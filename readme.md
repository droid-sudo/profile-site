# Shawn's Known Donor Profile

A responsive, privacy-conscious static website for intended parents.

## Structure

- `index.html` — overview, process, values, and contact
- `info.html` — personal background, education, and interests
- `result.html` — concise screening and records overview
- `why.html` — motivation, roles, and boundaries
- `photos.html` — privacy-first photo-sharing approach
- `style.css` — shared visual system and responsive layout
- `script.js` — accessible mobile navigation and light reveal effects

The existing `CNAME` and `vials.pdf` files should remain at the repository root when these files are published.
